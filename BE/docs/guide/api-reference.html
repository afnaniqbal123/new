How to read this page

Conventions

Authentication is on by default

There is a global access guard. A route is protected unless it carries @Public(), so the chips below describe what a route adds or removes, not what it opted into.

ChipMeans
publicNo token needed. Reached before a credential exists, authenticated by something else, or a health check.
bearerNeeds Authorization: Bearer <accessToken>. The default.
permissionAlso carries @RequirePermissions — a CASL check before anything is loaded.
recordThe service also runs assertCan on the loaded record. Required wherever a policy attaches a condition.
tenant@TenantScoped() — needs x-organization-id, and membership is verified.
signaturePublic, but authenticated by a provider signature header verified in the handler.
unverifiedTrusts a client-supplied identifier. A known hole, not a design.

Every response uses one envelope

{ "data": … , "status": 200, "message": "…" }

Read this before writing a client

Only /auth/* returns real HTTP status codes. Everywhere else — users, chat, notifications, media, Stripe, PayPal — a failure comes back as HTTP 200 with the real status inside body.status. So outside auth you must branch on the body, not the response code. It is tracked debt, not a convention to copy.

Request bodies are stripped

The global validation pipe runs with whitelist: true. Any property your DTO does not declare is deleted before the handler sees it — so sending an extra field is not an error, it simply has no effect. That is a security property: POST /auth/verify-reset-password relies on it to make a supplied email unreachable.

Auth

/auth@ApiTags('Auth')

Credentials and sessions. The only module that returns real HTTP status codes — 401 for bad credentials, 403 for a spent reset token, 429 for OTP cooldown.

Before a credential exists

POST /auth/verify-signup-otppublicemail, otpActivates the account. Only path that sets emailVerified: true, and it refuses anything not PENDING.

Refresh-token reuse revokes everything

Tokens rotate on every refresh. Presenting an already-rotated one is treated as theft and revokes every session for that user. A client that fails to persist the new refreshToken will log its user out everywhere.

Users

/usersreference module

The class declares @UseGuards(OrganizationAccessGuard, PermissionsGuard) — in that order, at controller level, because Nest only respects guard ordering within a single @UseGuards and the ability must be built after tenant context exists.

RouteAuthBody / queryNotes
POST /usersbearermultipart: name, email, phone, role, organization, avatarNo permission check. Any authenticated caller may create a user, including setting role. Tracked debt.
GET /usersbearer?searchNo permission check. Any authenticated caller may list every user in the system. Tracked debt.
GET /users/allbearertenantListheader: x-organization-idScoped to the organization the caller was found entitled to — not the one they asked for.
GET /users/:idbearerReadrecord—Guard checks the subject name; the service checks the record. Both are needed — see the two-stage note below.
PATCH /users/change-emailbeareremail, passwordPassword-verified. Sets emailVerified: false — and today nothing can set it back for an active account.
PATCH /users/mebearermultipart: name, phone, languagePreference, avatarSelf-service. Only those three fields are forwarded — role, email and password are dropped, so this cannot be used to escalate. Registered before :id so "me" is not matched as an id.
PATCH /users/:idbearerUpdaterecordmultipart: name, email, phone, role, password, languagePreference, avatarThe admin path. Field-level grants apply here.
DELETE /users/:idbearerDeleterecord——

Two routes carry no permission at all

POST /users and GET /users have never had a role or permission check. The CASL migration preserved existing behaviour rather than changing it, so they are still open to any authenticated caller. This is the most serious item on the repo's debt register.

WebSocket gateway

The handshake is not authenticated

ChatGateway trusts a client-supplied userId on connect and performs no verification — anyone can connect as anyone. It is flagged in the gateway itself and must be closed before production. The REST routes above are unaffected; they authenticate normally.

The module also reads the User collection directly for participant validation and search, rather than calling UserService. Deliberate, narrow, and baselined so it cannot spread.

Media

/mediabucket

The API never proxies file bytes. It signs a URL and the client talks to S3 directly — so uploads and downloads do not consume app bandwidth.

RouteAuthBodyNotes
POST /mediabucket/presign-uploadbearerfileName, folderName?, contentType?Returns a presigned PUT URL. folderName is a FOLDER_NAME enum value.
POST /mediabucket/presign-upload/bulkbearerfileNames[], folderName?, contentType?—
POST /mediabucket/presign-downloadbearerfileName, folderName?Returns a presigned GET URL, valid for AWS_EXPIRES_IN.
POST /mediabucket/presign-download/bulkbearerfileNames[]Ignores any folder you send and forces FOLDER_NAME.PROFILE.
DELETE /mediabucketbearerfileName, folderName?—
DELETE /mediabucket/bulkbearerfileNames[]Also forces FOLDER_NAME.PROFILE.

No ownership check on delete

These routes authenticate but do not verify that the caller owns the file being signed or deleted. Any authenticated caller can name any key in the bucket. Worth knowing before exposing this module to untrusted users.

Payment controllers take the user from the payload

Several Stripe and PayPal handlers resolve the user from the request body or raw request rather than the authenticated principal. They are authenticated — the global guard covers them — but they should read @GetUser. Tracked debt; do not copy the pattern into new code.

Modules with no HTTP surface

Four modules ship no controller. They are still part of the repo, and three of them are load-bearing.

ModuleWhat it isHow you use it
authorization@Global. The permissions mechanism — abilities, the route guard, record assertions, the policy registry.Import PermissionsGuard, @RequirePermissions, @GetAbility, Action. Register a policy from your own module.
emailProvider selection, Handlebars templates, sending.Inject EmailService. Your module decides when and passes the data; the template lives in email.
onesignalPush delivery.Inject OneSignalService.
announcementsnot wired A subject constant and an authorization policy with its spec — no module, controller, service or schema.Nothing yet. It is not registered in AppModule, so its policy never reaches the registry and grants nobody anything at runtime.
